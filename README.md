# ShopFlow DataOps

## Description
ShopFlow DataOps est un projet Data Engineering et DevOps visant à automatiser le traitement de données e-commerce.

## Objectifs
- Collecter et transformer des données e-commerce.
- Charger les données dans SQL Server.
- Automatiser les tests avec Pytest.
- Conteneuriser l'application avec Docker.
- Mettre en place un pipeline CI/CD avec Jenkins.
- Organiser le développement avec Jira et Scrum.

## Technologies
Python, Pandas, SQL Server, Docker, Jenkins, Git, GitHub, Jira.

## Sources de données
- Olist : données historiques e-commerce.
- Python et Faker : génération de données synthétiques.
